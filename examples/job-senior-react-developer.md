# Senior React Developer (remote, Europe)

Northwind Health builds a patient scheduling platform used by 400 clinics. We are looking for a Senior React Developer to lead the front end of our booking product.

## What you will do

- Own the React and TypeScript code base of the booking web app.
- Design reusable components with the design team and keep our UI library healthy.
- Improve performance and accessibility (WCAG 2.1 AA) across the product.
- Mentor two mid-level developers and review their code.

## What we are looking for

- 5+ years of front-end development, including 3+ years with React.
- Strong TypeScript skills.
- Experience with automated testing (Jest, React Testing Library or Playwright).
- Fluent English; French is a plus.
- Nice to have: Next.js, GraphQL, experience in health tech.

Full remote within European time zones. Salary: €65k–€80k.
